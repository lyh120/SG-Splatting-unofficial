# README image slots

Put these four PNG files in this folder so the top of the project README renders a 2x2 comparison grid:

- `train_gt.png`
- `train_render.png`
- `test_gt.png`
- `test_render.png`

Suggested sources:

- `train_gt.png`: a representative ground-truth image from `train/.../gt/`
- `train_render.png`: the matching final render from `train/.../renders/`
- `test_gt.png`: a representative ground-truth image from `test/.../gt/`
- `test_render.png`: the matching final render from `test/.../renders/`
